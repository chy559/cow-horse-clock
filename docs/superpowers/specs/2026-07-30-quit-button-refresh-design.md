# “收工”按钮视觉优化设计

## 目标

将仪表盘左下角过于弱化的“收工”文字按钮改造成符合现有打卡纸风格的退出按钮，让它与右侧“查看搬砖账本”入口在视觉重量上更协调，同时保持退出含义清晰。

## 设计

- 使用珊瑚色填充、黑色描边和圆角，形成小型打卡章外观。
- 电源图标放在文字左侧，文字使用黑色粗体圆体。
- 按钮轻微反向倾斜，增加手工盖章感。
- 使用现有 `hoverLift(.compact)` 动效：悬停上浮 3 点、轻微放大并出现硬黑投影。
- 增加“退出 CowHorseClock”帮助提示。
- 不修改退出行为、仪表盘布局结构或其他按钮。

## 验收

- 按钮在默认状态下清晰可见，不再使用低透明度灰色。
- 悬停表现与其他紧凑控件一致。
- 点击仍调用 `NSApplication.shared.terminate(nil)`。
- 应用测试、Release 构建、Info.plist 与代码签名验证通过。
