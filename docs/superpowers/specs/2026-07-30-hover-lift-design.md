# 牛马时钟悬浮凸起交互设计

日期：2026-07-30
状态：已批准

## 目标

为牛马时钟的可点击卡片和重要信息卡增加统一、明显但不过度的鼠标悬浮凸起效果，使界面更有纸片层叠感，同时强化可交互区域的反馈。

## 视觉参数

标准悬浮状态：

- 纵向上移 5px。
- 缩放至 1.015。
- 右下方增加约 5×5px 的黑色硬阴影。
- 提升渲染层级，避免阴影被相邻组件遮挡。
- 鼠标离开后以约 0.18 秒的短促弹性动画回落。

日期格、紧凑导航按钮等较小控件使用同一视觉语言，但位移与阴影缩小到约 3px，避免在密集布局中互相遮挡。

## 覆盖范围

### 可点击组件

- 仪表盘的设置入口和账本入口。
- 设置页的工作日历入口、返回按钮和主要保存按钮。
- 账本页和工作日历页的返回按钮、月份切换按钮。
- 工作日历中的日期格。
- 默认工作日选择按钮。

### 重要信息卡

- 仪表盘的“搬砖进度”和“本月累计”卡片。
- 账本的本月总额卡、图表卡和每日记录卡。

### 明确排除

- 薪资输入框。
- 时间选择器。
- 登录启动开关。
- 整个页面或整块日历容器。
- 普通文本和状态标签。

输入控件保留系统自身反馈，避免所有区域都呈现为可点击卡片。

## 实现结构

在 `PunchCardTheme.swift` 中新增可复用的悬浮修饰器：

- `HoverLiftStyle.standard`：用于普通卡片，5px 位移和阴影。
- `HoverLiftStyle.compact`：用于日期格、圆形工作日按钮和小型导航按钮，3px 位移和阴影。
- `View.hoverLift(_:)`：对目标组件应用悬浮状态。

修饰器内部维护单一 `isHovered` 状态，并组合 `offset`、`scaleEffect`、`shadow`、`zIndex` 与动画。组件尺寸和布局占位不变化，因此不会引发布局跳动或改变点击区域。

## 辅助功能

读取系统的“减少动态效果”设置：

- 正常模式使用位移、缩放与硬阴影。
- 减少动态效果模式取消位移和缩放，仅保留较轻的阴影变化。

悬浮反馈不替代原有按钮标签、辅助功能描述或点击反馈。

## 验证

- 运行全部现有业务测试。
- 完成 Release `.app` 构建与签名验证。
- 在仪表盘、设置、账本和工作日历逐页检查鼠标进入与离开。
- 检查密集日期格和相邻统计卡的阴影不被裁切。
- 检查悬浮后点击仍命中原组件。
- 检查开启“减少动态效果”时不执行位移和缩放。
