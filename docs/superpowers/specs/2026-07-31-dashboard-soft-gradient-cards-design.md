# 仪表盘柔和渐变卡片设计

## 目标

让仪表盘里的统计卡和操作按钮不再像硬切出来的方块：边缘带有轻微渐变，四角更加圆润，同时保留现有打卡纸风格和鼠标悬浮凸起反馈。

## 方案比较

1. **全局修改所有 `punchCard`（不采用）**：实现最少，但会同时改变设置、账本和日历，超出本次仪表盘范围。
2. **新增仪表盘专用柔和卡片样式（采用）**：为卡片加入左上到右下的轻渐变填充、渐变描边和柔和静态阴影，只在仪表盘使用。
3. **使用模糊玻璃材质（不采用）**：边缘更柔和，但会削弱应用已有的打卡纸质感，与当前高对比插画风不一致。

## 视觉规格

- 统计卡圆角由 `12` 提升到 `18`，采用 continuous 圆角。
- 设置、收工和账本按钮统一使用 `12` 圆角。
- 填充从左上保持原色，向右下渐变为较浅的同色。
- 描边由纯黑 2pt 改为深浅渐变的 1.5pt 墨色描边。
- 默认增加低透明度、轻微向下偏移的柔和阴影，避免边缘僵硬。
- 保留现有 `hoverLift` 悬浮位移、缩放和硬阴影反馈。
- 中间半圆仪表没有矩形容器，不额外套卡片。

## 实现边界

- 在 `PunchCardTheme.swift` 新增独立的 `softPunchCard(fill:radius:)` 视图修饰器。
- 只替换 `DashboardView` 中的统计卡和三个操作块。
- 不改变设置、账本、日历、业务数据、金额计算或面板尺寸。
- 不增加第三方依赖。

## 验收

- 仪表盘统计卡和按钮具备可辨认但不过度的对角渐变。
- 四角比当前更圆润，统计卡与小按钮层级清晰。
- 鼠标悬浮时仍有现有的凸起效果。
- 现有功能测试、Release 构建、Info.plist 和代码签名验证通过。
- 禁止调用 `pdftotext`。
