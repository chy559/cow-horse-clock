# 牛马时钟应用图标 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 生成一枚专属牛马计时表盘图标，制作完整 macOS ICNS 资源，并让构建出的应用包使用它。

**Architecture:** 使用内置 ImageGen 生成 1024px 图标母版，通过本地色键去背得到透明圆角 PNG，再用 `sips` 生成各尺寸并写入标准 ICNS 块。由于 macOS 26 的 `iconutil` 无法重新打包其自身导出的 iconset，生成过程使用 Python 标准库写入容器，并用 `iconutil` 反向解包验证兼容性；构建脚本只负责复制资源并写入 `CFBundleIconFile`。

**Tech Stack:** ImageGen、PNG、macOS `sips`、`iconutil`、Python 3 标准库、Bash、Swift Package Manager。

## Global Constraints

- 图标使用奶油黄、珊瑚红、墨黑，不包含文字或货币符号。
- 母版必须为 1024×1024，透明圆角有效。
- 保留 `Resources/AppIcon.png` 与 `Resources/AppIcon.icns`。
- 应用支持版本仍为 macOS 14，不新增第三方依赖。
- 禁止调用 `pdftotext`。

- [ ] **Step 1: 写失败的图标契约测试**

新增 `scripts/test-app-icon.sh`：

```bash
#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd -P)"
PROJECT_DIR="$(cd "$SCRIPT_DIR/.." && pwd -P)"
PNG="$PROJECT_DIR/Resources/AppIcon.png"
ICNS="$PROJECT_DIR/Resources/AppIcon.icns"

[[ -f "$PNG" ]] || { echo "Missing Resources/AppIcon.png"; exit 1; }
[[ -f "$ICNS" ]] || { echo "Missing Resources/AppIcon.icns"; exit 1; }
[[ "$(sips -g pixelWidth "$PNG" | awk '/pixelWidth/ {print $2}')" == "1024" ]]
[[ "$(sips -g pixelHeight "$PNG" | awk '/pixelHeight/ {print $2}')" == "1024" ]]
grep -q 'CFBundleIconFile' "$PROJECT_DIR/scripts/build-app.sh"
grep -q 'Resources/AppIcon.icns' "$PROJECT_DIR/scripts/build-app.sh"
```

在 `scripts/test.sh` 的测试二进制执行后加入：

```bash
"$PROJECT_DIR/scripts/test-app-icon.sh"
```

- [ ] **Step 3: 用内置 ImageGen 生成母版**

使用以下生产提示词，生成到纯 `#00ff00` 色键背景：

```text
Use case: logo-brand
Asset type: macOS application icon master, 1024×1024
Primary request: Create a distinctive icon for a humorous salary-tracking menu bar app called CowHorseClock.
Scene/backdrop: a perfectly flat solid #00ff00 chroma-key background outside the icon tile
Subject: a cream rounded-square paper tile; centered coral-red stopwatch face with thick black outline; one short cow horn on the upper left and one horse ear on the upper right; inside the dial, two bold clock hands form a simple upward earnings graph
Style/medium: polished vector-like flat illustration, punch-card print style, crisp geometry
Composition/framing: centered, generous safe margins, readable at 16px, no tiny details
Color palette: cream #fff6bd, coral #ff7357, near-black #171717, small white highlights; never use green in the subject
Constraints: no text, no letters, no currency symbols, no watermark; no photorealism; no gradients outside the icon tile; background must be perfectly uniform #00ff00 with no shadow or texture
```

将生成结果复制进工作区，然后用 imagegen 技能提供的 `remove_chroma_key.py` 去背，最终输出 `Resources/AppIcon.png`。验证 PNG 为 RGBA、四角透明、主体居中且无绿色边缘。

- [ ] **Step 4: 添加可重复的 ICNS 生成脚本**

新增 `scripts/generate-app-icon.sh`，用 `mktemp -d` 创建 `AppIcon.iconset`，从 `Resources/AppIcon.png` 生成：

```text
icon_16x16.png          16×16
icon_16x16@2x.png       32×32
icon_32x32.png          32×32
icon_32x32@2x.png       64×64
icon_128x128.png        128×128
icon_128x128@2x.png     256×256
icon_256x256.png        256×256
icon_256x256@2x.png     512×512
icon_512x512.png        512×512
icon_512x512@2x.png     1024×1024
```

最后用 `scripts/build-icns.py` 把现代 `ic07–ic14` PNG 层写入标准 ICNS 块（不写会被 macOS 26 误解码的旧式 `icp4/icp5` 块），并用系统工具反向解包验证：

```bash
python3 "$SCRIPT_DIR/build-icns.py" \
  "$ICONSET_DIR" "$PROJECT_DIR/Resources/AppIcon.icns"
iconutil -c iconset "$PROJECT_DIR/Resources/AppIcon.icns" \
  -o "$TEMP_DIR/Validated.iconset"
```

- [ ] **Step 5: 接入应用打包**

在 `scripts/build-app.sh` 创建 `Contents/Resources`，复制：

```bash
cp "$PROJECT_DIR/Resources/AppIcon.icns" \
  "$APP_DIR/Contents/Resources/AppIcon.icns"
```

并写入：

```bash
plutil -insert CFBundleIconFile -string "AppIcon" "$PLIST_PATH"
```
